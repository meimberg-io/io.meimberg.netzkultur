# Eine Kette von Anfang bis Ende

Ein Abschnitt, durch alle vier Stationen: Material, Outline, Briefing, fertiger Text. Dieselbe Sache viermal, jedes Mal eine Stufe weiter.

| Datei | Station | Wer macht das |
|---|---|---|
| [1-dossier-auszug.md](1-dossier-auszug.md) | Material mit Belegstatus | Recherche, laufend |
| [2-outline.md](2-outline.md) | was gesagt wird | Skill `editor-outline` |
| [3-briefing.md](3-briefing.md) | der Auftrag an den Schreiber | Skill `editor-write` |
| [4-abschnitt.md](4-abschnitt.md) | was zurückkommt | Agent `writer` |

Der Vergleich von 2 und 4 zeigt das Entscheidende: Der Text folgt der Outline inhaltlich exakt und ihrer Form kein bisschen. Keine Perle steht als eigener Satz, keine Station bekommt einen Ankündigungssatz. Genau dafür liegt die Liste beim Schreiben weg.

## Was du hier übernimmst und was nicht

**Die Machart, ja.** Wie ein Auftragssatz aussieht, wie fein das Material sein muss, wie kurz ein Briefing sein darf, wie viel Weggelassenes normal ist.

**Den Klang, nein.** Das Beispiel klingt, wie es klingt, weil ein bestimmtes Publikum gemeint war. Deine Stimme steht in `rules/stimme.md`, und nur die geht in dein Briefing. Wenn dein Werk anders klingen soll, ist dieser Beispieltext das falsche Vorbild.

Das Thema ist bewusst fachfremd, damit niemand versucht, hier Inhalte abzuschreiben.

Wenn dein Werk eigene, bessere Beispiele hat, ersetz dieses Verzeichnis dadurch oder lösch es.
