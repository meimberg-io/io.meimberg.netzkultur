# Outlines

Eine Outline je Abschnitt, benannt wie der Abschnitt: `01.03.md`, `02.07.md`.

Hier landet, was `/editor-plot` erarbeitet. Oli liest und korrigiert die Datei, danach nimmt `/editor-write` sie als Vorlage. Nur deshalb funktionieren die beiden Kommandos unabhängig voneinander und über Sessions hinweg.

Eine Outline ist Arbeitsmaterial, kein Werkstück. Wenn der Abschnitt steht und geprüft ist, kann sie weg. Diese Dateien tragen keinen Vertrag im Frontmatter, weil sie kommen und gehen.
