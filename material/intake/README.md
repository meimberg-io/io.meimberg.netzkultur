# Intakes

Ein Intake je Abschnitt, benannt wie der Abschnitt: `01.03.md`, `02.07.md`.

Hier landet, was `/editor-outline` erarbeitet. Oli liest und korrigiert die Datei, danach nimmt `/editor-write` sie und gibt sie dem Agenten `writer`. Nur deshalb funktionieren die beiden Kommandos unabhängig voneinander und über Sessions hinweg.

Ein Intake ist Arbeitsmaterial, kein Werkstück. Wenn der Abschnitt steht und geprüft ist, kann er weg. Diese Dateien tragen keinen Vertrag im Frontmatter, weil sie kommen und gehen.
